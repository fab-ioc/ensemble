Call an agent stalled after seconds

🔔 An agent that was asked to do something, isn't working, and hasn't reported back for this long is listed as needing you. Both CLIs redraw a working indicator while they think, so an agent busy for hours is never counted.

Backup of your projects

Your projects and their tasks live in one folder that the app keeps as a git repository. Give it a remote and it commits & pushes on a schedule — so a new machine gets every project and the knowledge built inside it.
