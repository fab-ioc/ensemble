Preferences

Default model for new sessions

Passed as claude --model <value> for + New sessions. Aliases (opus, sonnet, …) or full IDs both work. Empty = let claude pick.

What the agents call you

Used in the collaboration briefing, so agents address you by name instead of “the human.” Empty = your git user.name.

Call an agent stalled after seconds

🔔 An agent that was asked to do something, isn't working, and hasn't reported back for this long is listed as needing you. Both CLIs redraw a working indicator while they think, so an agent busy for hours is never counted.

Start the PO afresh past tokens

Every wake of a project's PO re-sends its whole conversation. Past this size the PO brings PO-HANDOVER.md up to date and a fresh session picks up from it and ROADMAP.md; the old conversation is kept. 0 = never.

Start a task's owner afresh past tokens

The same for the engineer (or only agent) of a running task: it writes TASK-HANDOVER.md in the task folder and a fresh session carries on from it. 0 = never.

RTK for task agents

Compresses command output for task owners and reviewers on their next launch. PO rooms, adopted sessions and your own terminals are never changed.

Backup of your projects

Your projects and their tasks live in one folder that the app keeps as a git repository. Give it a remote and it commits & pushes on a schedule — so a new machine gets every project and the knowledge built inside it.

Git remote (optional)

Only the URL is stored. Authentication uses this machine's git credential manager or SSH key — the app never sees a password or token.
