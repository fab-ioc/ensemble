Ingredient search: release plan

Recipe Box · prepared by the PO for the first release

Goal

People type one ingredient and see every recipe that uses it. The first release searches the small sample list that ships with the app.

Steps

Acceptance

  • Search ignores letter case: “Lemon” and “lemon” find the same recipes.
  • An ingredient no recipe uses shows a friendly empty message.
  • Tests cover a match, a miss and mixed case.

Risks

Plural ingredient names may not match: a search for tomatoes would miss a recipe that lists tomato.

Later

Saved favourites and a shopping list grouped by recipe follow once search is merged.
